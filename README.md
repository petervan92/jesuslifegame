# Christ Quest - A Life of Miracle

Game phiêu lưu 3D trên web về cuộc đời Chúa Giê-su, dành cho thiếu nhi 6-12 tuổi. Người chơi là nhân chứng đi theo câu chuyện.

- Mở `index.html` qua một máy chủ tĩnh (ví dụ `npx serve .`) để chơi.
- `js/engine.js`: engine dùng chung (cảnh 3D, dấu dẫn hướng, hội thoại, mini-game, trang kể chuyện).
- `js/characters.js`: bảng nhân vật. Sửa màu, râu, khăn, kích thước ở đây; hoặc thay bằng model `.glb` (hướng dẫn ở đầu file).
- `js/ch1_bethlehem.js`: Chương 1, Bết-lê-hem (ban đêm, Lu-ca 2).
- `js/ch2_jordan.js`: Chương 2, sông Giô-đanh (Ma-thi-ơ 3).
- `js/ch3_wilderness.js`: Chương 3, ba lần cám dỗ (Ma-thi-ơ 4).
- `js/ch4_capernaum.js`: Chương 4, Ca-bê-na-um (Lu-ca 5, Ma-thi-ơ 4).
- `js/ch5_galilee.js`: Chương 5, biển Ga-li-lê (bài giảng trên núi, năm bánh hai cá, dẹp yên bão, đi trên mặt nước).
- `js/ch6_road.js`: Chương 6, đường lên Giê-ru-sa-lem (Xa-chê, con chiên lạc, La-xa-rơ).
- `js/ch7_jerusalem.js`: Chương 7, Giê-ru-sa-lem (vào thành, tiệc ly, Ghết-sê-ma-nê, thập tự giá).
- `js/ch8_risen.js`: Chương 8, Phục sinh (mộ trống, Em-ma-út, bữa sáng bên bờ biển, thăng thiên).
- `jesus.html`: bản prototype 2D ban đầu.
